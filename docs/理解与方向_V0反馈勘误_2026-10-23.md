## 2. 由此固化的理解（V1 的纲）

1. **Saga = 一个人的技术型贸易 SOHO**。资源约束 = Simon 的时间；一切动作先问「省不省他的时间、有没有长期复利」。
2. **路线 = 技术绑定**：靠 Marvell 线（SmartByte / Peter）的管理型交换机 + 固件/MIB/配置支持，让客户把 Saga 写进自己的体系，慢慢撬动订单与该市场；CENTEC / Realtek 线是补充与敲门砖。
3. **区域 = 北美 + 全欧洲 + 土耳其**，其余被动承接；Simon 自己的《客户 & 市场 总结反思》再细一层：**土耳其、美国、英国、德国四国为主**，波兰次之，以色列一户突破，俄/尼/加各维持一户，DC 交换机客户单列重点。Mikrotik / Edgecore / Planet 的用户群 = Marvell 方案的存量市场，是将来重开挖掘时的矿脉。
4. **绑定三级** = 轻度（官网/项目用了型号）/ 较深（写进客户工具链，切换成本高）/ 深（体系融入，尚无）。20 家成单客户现状：NYNEX 较深（Simon 文档里原为轻度，GitHub 提交后升级）；PBA、Angora、James、Netaş、Mbata 轻度（Angora 卡门槛；依据见 §1a）；其余待按同一尺度归类（加厚时做）。Simon 的原则：「绑定了就互相成为一个系统了 = 可能会慢，但不会死，不容易出事」。
5. **物流两线 + 一条快递线**：客户自带货代（多在广州）vs Saga 货代百运网（深圳，DAP/FOB）；另有「客户 DHL/FedEx/UPS 账号」线（≤5,000 元简单文件；>5,000 元 Simon 以电子口岸盾自做电子申报）——见《发货方式及流程汇总.docx》（摘读 A19）。
6. **价格**：三档规则不变；群发历史低价不是策略；**现价已在仓库**——SmartByte 2026-09 价格册（管理型两册更新，有效期至 2026-12-30；另三册未变）= 价格主表基础；HRUI 现价 = 《洪瑞报价-天龙2026930》（2026-09-30，已入库 → `data/价格主表_HRUI.csv`；7 天有效、不含税含运费）。报价基数 = 价格主表 + 最近采购合同价交叉核对。（T29-U29 更正：此前写的「需 Simon 向供应商确认现价」有误，撤回。）
7. **加厚顺序** = A 全部 → B 欧美土 → 其余 B；时间在 V1 之后。
