## 2. 由此固化的理解（V1 的纲）

1. **Saga = 一个人的技术型贸易 SOHO**。资源约束 = Simon 的时间；一切动作先问「省不省他的时间、有没有长期复利」。
2. **路线 = 技术绑定**：靠 Marvell 线（SmartByte / Peter）的管理型交换机 + 固件/MIB/配置支持，让客户把 Saga 写进自己的体系，慢慢撬动订单与该市场；CENTEC / Realtek 线是补充与敲门砖。
3. **区域 = 北美 + 全欧洲 + 土耳其**，其余被动承接。Mikrotik / Edgecore / Planet 的用户群 = Marvell 方案的存量市场，是将来重开挖掘时的矿脉。
4. **绑定三级** = 轻度（官网/项目用了型号）/ 较深（写进客户工具链，切换成本高）/ 深（体系融入，尚无）。20 家成单客户现状：NYNEX 较深；PBA、Angora、James 轻度（Angora 卡门槛）；其余待按同一尺度归类（加厚时做）。
5. **物流两线**：客户自带货代（多在广州）vs Saga 货代百运网（深圳，DAP/FOB）。
6. **价格**：三档规则不变；群发历史低价不是策略；报价基数 = 最近采购价，并需 Simon 向供应商确认物料涨价后的现价。
7. **加厚顺序** = A 全部 → B 欧美土 → 其余 B；时间在 V1 之后。
