## 3. XA / XB / XC 标准草案（步骤 2 用；你认了就按这个，不认就改）

**XA（长期跟进）** 同时满足：
1. **渠道型买家**：分销 / 进口商 / 安防批发 / 系统集成商 / 自有品牌 OEM / WISP·MSP 装备商 / 电商卖家——会反复买交换机的人；
2. **在卖或在用交换机 / PoE / 网络设备**（有信号：MikroTik、Ubiquiti、Allied、Planet、Edgecore、Hik/Dahua、TP-Link…或自有品牌）；
3. **区域在主攻区**：美加 / 全欧 / 土耳其；
4. **有人可联**：公开商务邮箱或实名 KP（至少官网 + 表单可查）；
5. **不是排除项**（见 XC）。
   产品对位：mik 户 → SmartByte 商用 + **STI 工业补位**；Edgecore 户 → 商用/工业 **OEM + 低价**；CCTV 户 → **HRUI PoE 为主、SmartByte PoE 为辅**。

**XB（慢慢跟）**：满足 1–2 但区域在俄 / 印 / 韩 / 中东 / 东南亚 / 拉美 / 非洲 / 澳新；或在主攻区但只有 info@ / 表单；或是会自己采购的终端大用户（学校集团、医院集团、酒店集团的 IT 部）——先 B，等信号。

**XC（不跟 / 情报）**：非买家触点（机场、博物馆、超市、监狱、港口、教会、工厂……只是「谁会用 PoE」）、同行（ONV/UTEPO/深圳 OEM…）、芯片原厂、VMS 软件商、展会大牌（Axis/Altronix 类）、超大集团（Ingram/TD Synnex/ALSO/Bechtle 类，决策链太长）、大陆公司、守界行业（轨交 / 军工 / 海事 / IP67 / 云管）、死域名、**重复**（已在 Saga Clients 或库内重复）、我们的供应商（HRUI / SmartByte / HOHUNET 自己）。
