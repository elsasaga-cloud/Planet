## 4. 关仓后怎么复跑

- 提取脚本需要克隆在 `/home/user/.cache/ext/{edge,mik,cctv}`：关仓后用压缩包解包到同路径即可（`mkdir -p /home/user/.cache/ext/edge && tar -xJf data/external_repos/archive/Edgecore_729187d_文本全仓.tar.xz -C /home/user/.cache/ext/edge`，其余同理）。三个脚本的 `git rev-parse` 失败时自动落回 `<sha>(archive)` 标签，不再依赖 .git。
- Edgecore 的 xlsx 补录读的是 `data/external_repos/edgecore_xlsx/*.csv`（不依赖 openpyxl）；mik 的 10 家 DOC 补录是脚本内置表。
- 顺序不变：`extract_edge.py` → `extract_mik.py` → `extract_cctv.py` → `render.py`（预期 edge 27/101/109 · mik 509/180/353 · cctv 30/1371/1671）。
