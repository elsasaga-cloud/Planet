## 2. 「再去过一遍客户 = 调研 + 加厚」的判据

- **5.1 已深挖过的**（Saga A 全部、Saga 老 B、External 有研究卡的 XA）：本轮不动。
- **5.2 没深挖过的**（C→B 捞出、冷 B、External XC→B、Planet 捞出）：必须过。**留 B** 要同时满足：
  1. 行业内 ✔（安防 / IT / 网络 / 工业网络的分销、集成、安装、自有品牌、网店，或终端但有复购）；
  2. 对位 ✔（在卖或在用交换机 / 收发器 / PoE，与 Saga 主表有同口型）；
  3. 有成单可能 ✔（进口中国 / 台湾同类的记录、渠道名录、商品页、成单 / 样品 / 回信 / 具体需求 任一）。
- **打回 C 储备**（可逆：回信 / 询价 / 收款路径解决即回 B）——四类：
  - 微型网店 / 一人店且无进口证据（Q-33 经销体系现供的微型户也在此）；
  - 登记休眠 / 主体不明 / 经营范围对不上；
  - 未坐实 + 无路径（邮箱 fail、域名不可达）；
  - 红旗（仲裁 / 执行 / 制裁待核）+ 收款未清；纯光端机终端 + 区域外（Q-70 dayjob_fit）；非本行业 / 非采购主体（代理、销售代表公司）。
- 边界口径：微型 + 有进口证据 = 留 B（预付 100%）；q33_hold 的 ★ 品牌商留 B「只盯不发」；巨头留 B 长线；RU/BY/KZ 留 B「只盯 + 季度一封」收款待定；全退信（SC-634）留 B 补路径；业务「待核」而研究档判不了的 → 继续待过（不乱打回）。
