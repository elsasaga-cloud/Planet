# 客户分级、编号与去重规则（Planet 仓库 · 2026-10-19）

> 继承 Mikrotik 仓库 R38–R53（定级）、R59（去重/编号冻结）、R70（C 类清理）规则；本文件只写 Planet 仓库的落地口径与差异。

## 1. 谁是客户（前置过滤）

| 判定 | 结论 |
|---|---|
| PLANET Technology Corp. 本身、PLANET 自营/关联的各国 PLANET 公司（名称含 PLANET 且由台湾母公司控股或作为品牌区域办事处运作） | **不是客户**，仅作信号源；记入 `docs/methodology/死路与死链备案.md`「信号源名单」 |
| 区域外（中东、拉美、亚太、非洲）的 PLANET 渠道 | 不入主表；在批次 JSON 的 `skipped` 里写名字 + 原因（每个跳过的名字都要有解释） |

| 中国大陆公司 | 不入主表（R70 口径） |

## 2. ABC 定级（不改 Mikrotik 规则）

| 级 | 条件（全部满足） | 细分 |
|---|---|---|
| **A** | ① 有可追溯的接入层/PoE/工业交换需求证据（在卖 PLANET 交换机、做 CCTV/园区/工业项目、自有品牌/贴牌）；② 有**具名的人**或可直达的角色邮箱；③ 体量可拿下（非大集团）；④ 欧洲或美加 | A-集成商 / A-方案商·品牌商（OEM）/ A-技术型分销 |
| **B** | 有公开邮箱可群发，但需求证据只到「名录/品牌页」级，或只有通用邮箱 | B-分销商 / B-电商 / B-集成商（待具名） |
| **C** | 无邮箱 / 体量过大 / 区域外 / 业务不对口 / 只剩表单 | C-无邮箱 / C-体量过大 / C-区域外 / C-不对口 / C-信号源 |

- 初次入库时给 **初评**（基于名录与品牌页信号）；联系方式研究后再 **复评**；`人工定级` 列由用户填写，优先级最高。
- 升降级只改 `评级` 列与档案目录，**不改编号**。
- 集成商/方案商优先于分销商（Mikrotik 实测 A 率 34.5% vs 3.7%）。
- 用户背景文档优先级：OEM/ODM 品牌商/方案商 > 有中国进口或台系合作经验的渠道 > 分销/电商 > 小型集成商。

## 3. 编号

- 格式 `PA-001` / `PB-001` / `PC-001`（P = Planet 仓库，避免与 Mikrotik 仓库 A-/B-/C- 混淆）。
- 按入库先后在各级内递增；**冻结、只追加、不复用、不回填**。合并重复时保留先号，后号在 CSV `状态` 写「并入 PX-xxx」，档案保留并加合并说明。

## 4. 去重

1. 键：`国家 + 规范化公司名（去法律后缀 GmbH/Ltd/S.r.l./S.L./Sp. z o.o./B.V./ApS/AB/AS/Oy/SAS/Inc./LLC 等后小写去标点）`，同键视为同一户；**不同国家同名 ≠ 重复**。
2. 子串匹配只作提示，不自动合并（Sphinx France vs Sphinx Connect 教训）。
3. 跨仓去重：与 Mikrotik 仓库主表（`data/Mikrotik仓库已有PLANET相关客户_对照.csv` 26 行 + 全表 1,032 行离线核对）比对；已在 Mikrotik 仓库建档的，本仓库 **仍可入库**（因为本仓库以 PLANET 渠道为主题），但 `Mikrotik仓库对照编号` 列必须填其编号，并在档案开头注明「Mikrotik 仓库已有档案 X，本档只补 PLANET 侧证据，联系策略以先建档案为准」。
4. 每个跳过/合并的名字都要在批次 JSON `skipped`/`merged` 中给出原因。

## 5. 主表字段（`data/客户名单_Planet渠道_2026-10.csv`）

前 22 列与 Mikrotik 仓库完全一致（便于日后合并），后 4 列为 Planet 仓库新增：

```
公司名, 国家, 城市, 网站, 类型, 信号（在卖什么品牌）, 是否自有品牌, 切入点, 首推Saga型号, 入口/联系方式,
优先级, 状态, 来源, 首次触达日, 最后互动日, 下次跟进日, 备注, 评级, 评级依据, 档案编号, C级细分, 人工定级,
PLANET关联证据URL, Mikrotik仓库对照编号, 入库批次, 入库日期
```

- `类型` 取值：分销商 / 电商 / 集成商 / 方案商·品牌商 / 安防经销 / 工业自动化经销 / ISP·WISP / 其他（写明）。
- `来源` 写「方法编号 + 检索词」（见方法论），保证可复现。
- `状态` 取值：00-未触达 / 01-已跟进一轮 / 02-有回复 / 03-样机 / 04-成交 / 09-停止（原因）/ 并入 PX-xxx。
