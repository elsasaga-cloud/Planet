## 1. 身份

- 中国大陆交换机**贸易公司**（SOHO），官网 <https://sagatele.com/>（用户自评：官网效果差，影响信任——话术里少引导去官网，多给规格页/样机）。
- 货源结构：
  - **接入层**（核心）：Marvell 方案为主 → SmartByte（<https://www.smartbyte-switch.com/>）：CCTV 交换机、商业/工业 PoE（8/16/24/48 口）、L2+ 管理型；Realtek 方案为辅 → HRUI（<https://www.hruitech.com/>），补型号、给价格敏感客户。
  - **汇聚/核心层**：CENTEC 方案 → Hohunet（<https://hohunet.com/>）：L3、10G SFP+ 汇聚、核心。
- 对外品牌：Saga / Saga Telecom（型号 STC-/STI-）。

## 2. 优势（用户原话要点）

1. 功能强：ERPS 环网、PoE++、IGMP Snooping、VLAN、QoS；接入层 Marvell 方案性能稳定；三家供应商研发投入大、售前售后好。
2. 价格：**「与台湾同行差别不大，但性价比更高」——注意是和台湾同行比**；和大陆同行比一般。
3. 可定制：OEM/ODM 贴牌；**管理功能/界面深度定制**（不是简单换 logo）；芯片有库存、长期稳定供货、交期快。

## 3. 劣势 / 边界（定级与话术必须遵守）

1. 贸易商身份，加价空间有限（「给我 100，我最多卖 130」）。
2. **不做**：云管理、轨交交换机、IP67、消费级/家用路由。客户主营轨交 → 基本 PASS。
3. 官网弱。
4. 认证：只有 **CE / RoHS / FCC / REACH / UKCA**；**无 UL**、无轨交等行业认证、无 E-mark、无 KC 等强制准入。

## 4. 目标客户（用户排序）

1. **品牌商 / 方案商（有 OEM/ODM 需求）→ 最优先**；偏技术的客户谈深度定制（功能、管理 UI）——核心差异化。
2. 明显有从中国进口经验或合作供应商者（Utepo / ONV / UNIPOE / HRUI / Scodeno 等）；**在和台湾品牌合作的也可以（ORing、PLANET、Edgecore 等）**——长期潜力客户，慢慢跟。
3. 分销商 / 电商（卖现成品牌、要现货标品）→ 可跟（可 OEM、有芯片库存、交期快）。
4. 集成商 / 项目商（CCTV / 工业 / 园区）→ 可跟，**最好是小项目**；公司规模与业务范围别太大，大集团很难拿下。

## 5. 策略（用户原话要点）

1. 长期跟进为主，不追求快速成单；客户在意价格/公司实力 → 我方吃亏；在意 capability/功能 → 我方很强。
2. 偏好**项目型**（弱化贸易商身份，聚焦方案可行性与让利）与**技术型**（CLI / MIB / 深度功能是主场；升级与长期支持好）。
3. 长期从大陆进口的客户也是目标；「1 次跟进不行就 10 次，10 次不行就 2 年 5 年」。

## 6. 对 PLANET 渠道挖掘的直接推论

- PLANET 的欧美渠道正是第 4.2 条「在和台湾品牌合作」的客户池：他们已接受台系价位（Saga 相对台系有性价比）、已习惯亚洲供货。
- PLANET 渠道里**集成商/安防经销/工业自动化经销**比纯 IT 分销更接近 4.1/4.4；PLANET 的 OEM 客户（贴 PLANET 白牌的品牌商）最接近 4.1。
- 话术避开 Saga 没有的 PLANET 卖点（LCD 触屏、bt 95W 商用线、云 NMS、EN50155、IP67），主打：ERPS<20ms、L2+/L3 全功能、CLI/MIB/深度 UI 定制、3 年工业保、交期与芯片库存、中性贴牌。
