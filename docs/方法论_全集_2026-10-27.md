## A. 信息怎么进来（读取与入库）

### A1 · 读外部 Google Drive 链接（连接器路径，≤100 MB 的小文件 / 文件夹盘点）

**解决什么**：Simon 发来一个 Drive 分享链接（文件、Google 文档、文件夹），要读进来并留档。

**步骤**
1. **从链接里取 ID**：`/file/d/<ID>/`、`/document/d/<ID>`、`/spreadsheets/d/<ID>`、`/folders/<ID>`、`?id=<ID>` 五种写法都取 `<ID>`。
2. `list_connector_tools("google_drive")` 加载工具 → `get_file(<ID>)` 先拿元数据（名字 / mime / 字节 / **md5Checksum** / 父文件夹 / 权限）。
3. 按类型读：Google 文档 / 表格 → 导出文本（表格导 CSV 逐表）；PDF / docx / xlsx ≤100 MB → `read_file_text`；**docx 里有表格、或 PDF 是扫描件 → 不要信连接器的文本**，改走 §A2 管道（表格会丢、扫描件读不出）。
4. **文件夹**：`list_files(parent=<ID>)` **逐层**列（整盘一次 200 行会截断——记入死路），每个文件抄 5 个字段 **文件名 / 文件类型 / 文件大小 / 所在子文件夹路径 / ≤50 字内容摘要**（T23 口径），摘要来源分三档标注：`读取内容` / `型号解码` / `文件名推断`；汇总脚本 `scripts/drive_smartbyte_index.py`、`scripts/suppliers_drive_index.py`、`scripts/drive_r3_index.py` → `data/*_drive_index.json`。
5. **对账**：清单条数必须与 Drive 全局计数对平（`'me' in owners` 且非文件夹），按 PDF / PNG / JPEG / 其他四桶逐桶对——第三轮就是这样抓出 95 个漏抄文件（递归列目录在「既有子夹又有文件」的目录上只取了子夹）。
6. **留档**：读过的内容写成 MD（英文原文逐句保留，头部写 Drive id / 链接 / 抓取日期），放 `docs/drive/`、`docs/reference/`；**读过 ≠ 入库，入库 ≠ 读过**，两者都要在台账里打勾（`docs/入库完整性总审计_2026-10-22.md`、`docs/信息源全覆盖核对_2026-10-23.md`）。
7. **隐私**：需要匿名下载时用连接器 `make_public(role=reader, allow_file_discovery=false)` 临时开「知道链接者可查看」，跑完 `make_private` 改回；Simon 只在我回复「入库完成，可以删」之后才删云盘原件。

**坑**：外部人共享给 Elsa 的文件（如 andatelecom1 的测试报告）要先「创建副本」到 Elsa 名下再入库；Drive 回收站 30 天内仍占配额（15 GB 不可扩）；文档 Tier 分层（Tier 1 全文入库 / Tier 2 索引 + 按需 / Tier 3 只索引）见 `docs/drive/00-Drive盘点与入库方案.md`（2026-10-20）。


**规模参考**：313 成员 6 min；2.38 GB PI 包 52 min；6.48 GB mbox 35 min；4.36 GB Extra Info（OCR 开）39 min。
**诞生**：T28 2026-10-22 01:09Z（SmartByte 文件夹），通用化 T29-U38 2026-10-24 02:30Z。
