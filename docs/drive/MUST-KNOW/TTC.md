TTC (Technology Transfer & Cooperation) focuses on building deep and practical partnerships through staged technical collaboration covering
1. OEM = Original Equipment Manufacturing
2. ODM = Original Design Manufacturing
3. SKD = Semi-Knocked Down
4. CKD = Completely Knocked Down
5. SDK = Software Development Kit Integration
6. Source Code Cooperation = Controlled Source Code / Joint Development

With the growing trend toward localized manufacturing and controlled hardware & software design, we are open to cooperating with our clients under appropriate and well-defined frameworks. Below is our cooperation strategy and capability overview

## 1. OEM – Original Equipment Manufacturing — Status: Readily Available
OEM is our most common and well-established cooperation model. We support customization including, but not limited to: Product branding / Web UI / Packaging boxes / User manuals / Labels and markings. This mode is flexible, efficient, and suitable for most commercial projects

## 2. ODM – Original Design Manufacturing — Status: Negotiable
ODM cooperation is possible under specific conditions. R&D must be conducted based on our existing PCB platforms. Certain requirements apply, including MOQ and associated development costs. We will integrate our supplier resources and technical capabilities where applicable

Reference Cases
- Case 1: A client requested joint PCB design for an IoT board with reasonable volume and continuous demand. This project was not pursued, as our core focus is Ethernet switches and IoT boards fall outside our product category
- Case 2: A client requested modification of power input (PIN definition, physical size, etc.) to fit their chassis system. Although the samples were supplied by us, the project could not proceed due to MOQ constraints

## 3. SKD – Semi-Knocked Down — Status: Readily Available
As a manufacturer, SKD cooperation is straightforward for us. Please advise: How you prefer the parts to be packed / Import and local assembly requirements. We will arrange packaging accordingly

## 4. CKD – Completely Knocked Down — Status: Negotiable
CKD cooperation usually involves confidential technical information, including: BOM lists / Schematic designs / PCB layouts. This mode is based on solid long-term cooperation and bulk orders, and is subject to specific terms such as MOQ and cost

## 5. SDK Integration — Status: Negotiable
We primarily focus on Marvell-based managed networking solutions. Marvell SDKs (typically SDK Lite or Prestera SDK/SDK-X) are under controlled licensing. End customers are encouraged to apply directly to Marvell. NDA (Non-Disclosure Agreement) is usually required. For more information, please visit: https://www.marvell.com/contact-us.html and submit the required project details (design intent, application scenario, etc.)

## 6. Source Code Cooperation — Status: Unavailable / Non-negotiable
Source code cooperation is not available and not negotiable in our business mode
