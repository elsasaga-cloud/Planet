## 一、先说边界（能查到什么、查不到什么）

| 想要的 | 能不能 | 为什么 |
|---|---|---|
| 美国客户从中国海运进了什么、谁发的、哪天到港、多重多少箱 | **能** | 美国海关舱单公开，ImportYeti 免费页给到港日 / 发货人 / 重量 / 件数 / 品名 / 集装箱数 |
| **金额（货值）** | **不能** | 美国舱单不含发票金额；页面上的「Est. Shipping Spend」是 ImportYeti 估的**海运费**，不是货款。本表所有「$」都是运费估算 |
| 空运 / 快递（DHL、FedEx）/ 陆运 | **不能** | 舱单数据只有海运；交换机这种轻货很多走空运，所以「查无」≠ 不进口 |
| 欧洲 / 土耳其 / 英国 / 加拿大客户的进口 | **不能（按公司）** | 这些国家海关数据不按公司公开；加拿大户若经美国港口转运才看得到（Lin Haw、Infinite Cables 就是这样看到的） |
| 印度 / 巴基斯坦客户 | **能但未做** | Zauba / Volza 有逐单含金额的数据（SB-869 早先已用 Volza 核过 128 单）；本轮先做美国，Q-63 决定要不要补 |
| 中国出口端（我们这边）数据 | **不能** | 中国海关不公开企业级出口明细 |

本轮查了 **62 户**（A 15 / B 47；美国 A 全部 15 户 + 美国 B 按热度顺序 45 户 + 加拿大经美转运 2 户），查到 **41** 户有海运提单，**21** 户查无。

   - SB-761 SCW / Security Camera Warehouse (Asheville, NC) ← UNV 宇视 · 77 票整包，2026-08-26 / 09-02 提单明写 Ethernet Switch

   - SB-221 Tycon Systems (Bluffdale, UT) ← HRUI 洪瑞 4 票 PoE switch（主供台湾 Mstronic 385 票）
   - SB-303 Watchnet (Markham, ON — 经美国港口转运加拿大；库里登记为 US) ← Shenzhen Utepo 优特普 4 票 PoE switch（2022-02 → 2023-12）→ 2025-04-26 换成 Shenzhen CSE 1 票 23 ctn；每 1～1.5 年换一次中国 PoE 交换机供应商

2. **GW Security（SB-108）就是 HRUI 的美国直客**（14 票、最近 2026-10-14 170 箱、年 3 票）：给他们推 HRUI 同款 = 自己打自己，只推 Marvell 管理型 / CENTEC 这类 HRUI 没有的；且他们走 LCL 到洛杉矶，有现成拼箱通道，样品可以搭。
3. **Signamax（SB-780）是 ONV 的最大美国客户**（35 票 ONV 交换机、2026-07-12 还在来），迈阿密 96% LCL。ONV 的 PoE 交换机与 HRUI/SmartByte 同价位段，这是「换供应商」型机会：要价格表对位 + 替代型号（STC-2024GP / STC-424XGGPM 对位 ONV 24 口 PoE），不是「新品类」型。
4. **Nelly's（SB-248）/ IPCamPower（SA-046）是一家人**：Sean Nelson 2016–2022 用 Nelly's 名义从 ONV 进了 15 票 PoE 交换机，2023 把 Nelly's 卖了专做 IPCamPower；IPCamPower 名下查无海运 → 他现在的 PoE 交换机要么空运、要么用别的主体。对 SA-046 的话术：他自己就是 ONV 的老买家，知道中国 PoE 交换机的价格与坑，直接谈规格和 MOQ，不用科普。
5. **Optiview（SA-021）的中国 PoE 交换机供应商 Shenzhen Centro 从 2024-09-28 后没再发过**，2025 全年 Optiview 没有任何 PoE 交换机海运记录 → 要么改空运、要么换了供应商/断了。这是 A 级里最像「正在找新供应商」的信号，值得一封专门的信（不提 Centro 名字）。
6. **Montavue（SB-951，Dahua 美国 OEM）海运 2024-04-16 后全停**；Nelly's 2024-10-17 后全停；KBC 美国 2021 后全停；Patton 2017 后全停——这四户「断流」要么是改空运、要么业务收缩，群发时不要按「活跃进口商」对待。
7. **台湾 ODM 是美国品牌商交换机的主流来源，不是中国**：EnGenius（Senao 100%）、Mako（Emplus，2025 起每票 500–720 箱）、Lin Haw（Planet）、Tycon（Mstronic 385 票）、Patton（自家台湾厂）。这些户换供应商的门槛是「固件/云管理适配」而不是价格——Mako 2020 年试过 ONV 一票 18 箱就没续，就是例子。
8. **「整柜进口商」是最容易搭货的**：52 Networks（SB-020）每年 2–3 个整柜网线从深圳光明/广州白云发，最近 2025-10-13；Lin Haw（SB-1127）月月一柜机柜从香港 Safewell 发；Altelix（SB-1001）8.4 TEU/月户外机箱+天线从宁波发；Fibertronics（SB-1030）月 1.4 票光纤配线从宁波/深圳发。这些户一句「下次整柜顺带 2 箱交换机样机，运费几乎为零」比任何价格话术都实在。
9. **海关里有一批「已经在买中国 PoE 交换机、但不在我们库里」的美国进口商**（见第五节）：Components Specialties（Amityville NY，HRUI 9 票，2026-10-12 还在来）、Spectrumvoip（Irving TX，HRUI 9 票）、Interwebz Distributing（Broken Arrow OK，ONV 2 票）、Tristate Telecom（Suffern NY，Centro PoE switches）、Syncom Technologies、Vino Technologies、Videoworld、Great Wall Security、PoE Texas、CCTV Supply——都是 Simon 要的第二梯队「有进口经验者」，要不要建档 → Q-63。
