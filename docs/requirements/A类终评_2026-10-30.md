## 0. 规则（Simon 原话要旨 → 执行口径）

1. **A 的主力军 = 成单客户 + 有过回信沟通的客户**；再加大池里极贴合 Saga 产品线 / 想法的户；先 A 后 B。
2. **成单只认 PI 包 20 户**（Simon 2026-10-30：「Saga 的成交客户就那 20 个 … 其他的都不算成交」）——表格备注里的「成单/样品单」是 Simon 本职公司时期的单，不是 Saga 的；`客户主表` 的「成交」列已改为只标 PI 包，另加「备注提及成交(非Saga)」列；MD 里的「老客户回访 / 感谢上次订单」话术只对 PI 包 20 户出现。
3. **「回信」按实质认**：问价 / 要样 / 要规格 / 报数量 / 谈项目 / 约谈 / 提 OEM 才算；自动回复、工单、休假、卖家反推销、只一句 thanks 不算；最后一句硬婉拒不进 A；2022 年前（Saga 之前）的互动、问的是 Saga 产品线外（AHD/HDMI/光猫/线缆…）的不算。Simon 表内备注里记的当面 / WhatsApp 对话（「问了 2 款 2.5G 价格」这类）算回信。
4. **有实质回复的逐户深挖核验（A-DEEP-01）**：六项——① 身份（登记 / 官网 / 法定名）② 角色与对位（分销 / 集成 / OEM 品牌 / ISP / 终端；是否卖或用交换机·PoE·工业·光纤）③ 需求证据 ④ 路径（企业邮箱 MX / WhatsApp / 最近来信距今）⑤ 规模 ⑥ 否决项（婉拒在后 / 守界 / 巨头 / 同行卖家 / Q-33 / 台湾 / 中国大陆 / 轨交军工主业）。六项过 → 留 A；不过 → 下放 B。网查补缺口的（11 户）每条带 URL 写进研究档。
5. **B/C 之间只做一件事**：有实质回复的 C 捞到 B（U128 ②）；其余 B/C 不动。
