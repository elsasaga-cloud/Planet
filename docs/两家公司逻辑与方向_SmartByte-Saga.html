三句话判断
  • 逻辑：SmartByte 以「低 MOQ 免费贴牌 + 自研 Marvell 固件 + 5 年机壳/孔位不变」换取 Saga 这类海外品牌商的长期出货；Saga 以「不做自有工厂、不碰源代码、不比 Realtek 低价」换取 SmartByte 的价格空间（「目标是出货，利润不很 care」）与研发直接参与售后。
  • 方向：SmartByte 2026 年全面切到 AC5（AC3 已于 2026-07-31 停产）、补 L3 / 7.5.0 固件、做白盒数据中心与 Centec、2027 才碰 TSN / EN50155；Saga 2026 Q3 把自己重新包装成「Managed Networking Solutions（接入到核心）」方案商，弱化「Marvell」字眼、引入 CENTEC 与 DC 交换机，市场重心 DE / UK / TR / IT，另以 PLANET 渠道池开拓 US/CA + 欧洲。
  • 卡点：土耳其大单（TT 800→1500 台、Angora 1000+ 台 L2+）连续延期；2026 存储涨价推高全线 +10 USD；Saga 无退税资质、无 UL、官网弱；两家合作的价格与开案规则已经成形，但 2026-09 新价格表尚未同步到 Saga 对外报价（待办 #7）。

6 · 方向：各自的与共同的

SmartByte 往哪走

  • 平台：AC5 全面化（AC3 停产），AC5 工业机壳 / 孔位 5 年不变；AC5X 2.5G + 25G 商用；白盒 DC（Aldrin2 → Falcon → Teralynx）；Centec 平台管理型（2026）。
  • 软件：7.5.0 加强 L2+（IGMP/PIM-SM、MQTT、LLDP-MED）；L3 继续 CLI-only；2026 工业协议（1588 PTP / Modbus / Profinet），2027 TSN / EN50155——都在路线图，不在当前报价范围。
  • 商务：价格随 BOM 走（2026 两次上调），价格表制度化（季度有效期）；MOQ 门槛明确（新品 ≥500 / 单且 ≥2K / 年）；希望 Saga 转含税口径、要 Realtek / 博达价格情报。
  • 不做：SD-WAN、OpenFlow、MPLS、Stacking、100G（2 年内）、DC 软件、IoT 板、低价 2.5G 红海（RTL8373 / MaxLinear）、Amazon 库存模式。

Saga 往哪走

  • 定位：从「卖 Marvell 交换机的贸易商」→「Managed Networking Solutions 方案商」：接入 Marvell（SmartByte）+ 汇聚 / 核心 CENTEC（Hohunet），卖「架构连续性」而不是单品；文件化的 CCF / TTC / 保修 / 订单流程 / 杂费表 / FAQ 做成客户可自助下载的资料包。
  • 市场：DE / UK / TR / IT（PROFILE 2026Q3）+ 本仓库的 US/CA + 欧洲 + 土耳其渠道池；小国不主动挖；UA / 军工 / 公共部门 / 轨交 / 生命安全守界。
  • 客户优先级：OEM/ODM 品牌商与方案商 > 有中国进口经验或在用台系品牌者 > 分销 / 电商 > 小项目集成商；A 级 = 真实可追溯需求 + 直接具名联系人 + 拿得下的规模。
  • 方法：长期跟进、不做广告、单一 P1 型号 + 一个问题的首触邮件、中性包装、不提产地；售后标准化（视频 + 图 + 文字、Zoom、模板与存档）。
  • 产品面：L2+ 规格书全部更新到 7.5；跟进 AC5 L3 规格书；Web / CLI 手册 7.5 版与新 catalog；等 SmartByte 的光模块常规价格表。

两家的共同方向（已被双方行为证实的）

  • 把 AC5 做成 Saga 工业线的 5 年基座（机壳 / 孔位 / CLI 不变），用「长期稳定 + 深度定制 + 交期」对抗台系与 Realtek 低价。
  • 土耳其是双方共同押注的市场（TT / 警察 / Netas / Angora 大标），其次德国（双 AC、风扇 MIB 的需求直接改了固件）与加拿大（16+2 10G 升级）。
  • 研发直接面对终端（扫地僧进客户群、晚间远程）+ Saga 做一线筛选（视频 + 口述）——这是两家合作里最像「一家公司」的部分。
  • 资料透明化：SmartByte 官网 2026-09 改版（规格书可下载、路线图公开）与 Saga 的 buffet-style 资料包同步出现。
