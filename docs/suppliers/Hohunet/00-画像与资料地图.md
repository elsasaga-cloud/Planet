## 6. 与 Saga 型号 / 产品线的对照
- Saga 品牌：**STH-** 前缀 = CENTEC 高速系列（唯一来源 Hohunet）；STC/STI = Marvell / Realtek 接入层。无撞名风险（STH 仅此一线）。
- 软件口径：STH 客户问功能 → 答 STOS 清单（分 EB/MS/MA license 档）；涉及 MPLS / EVPN / BGP 等运营商特性只在 STH 上承诺（`docs/drive/Resource-Library/STOS软件特性清单_V2.4_节选.md` 「对销售的用法」）。
- 对 PLANET 渠道客户的意义：PLANET 渠道里做园区核心 / 10G-25G 汇聚的集成商（profile 里「核心/汇聚」需求的 A/B 户）可用 STH 线补一句「also 10G/25G/100G aggregation on request」，但不主动推数据中心 400G/800G（超出 Saga 守界与服务能力，按项目评估）。
