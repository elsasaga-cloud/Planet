让数据跑更远、更安全的“监控型”PoE交换机

近年来，国家大力推进平安城市建设，随着建设规模的不断壮大，各行业对于监控数据传输设备的需求日益增大，与此同时如何选择合适的、满足监控整体网络架构性能的交换机，也有了更高的要求。

      

       百兆长距离POE供电交换机系列适用于多种应用领域，如网络监控、无线AP、IP电话以及无线覆盖、楼宇门禁等，能自动检测和识别符合PoE标准的网络摄像头、无线AP、网络电话、可视对讲门铃等并为其供电，使它们不受线缆布局限制，将数据和供电传输延长至250米，扩大了PoE供电的应用范围，让数据传得更远、更安全、位置安装更灵活。

250米长距离POE供电

千兆8+3口、16+2+1口长距离POE交换机系列提供多种工作模式，包括默认配置模式、长距离模式，根据用户需求，拨动拨码开关即可进入相应的模式，及时生效，无需重启交换机。

       产品万兆核心交换机HR-SWTG342408、HR-SWTG34240F8提供了更多的更新功能，支持算去Dos攻击防范和SNMP，具有相当的革命性，因此，能更好的满足网络安全、服务质量、链路保护等多个方面需求。网吧行业网络建设的主要目的是将网吧网络的性能、带宽、主要网络业务进行全网的建设，建设成一个“利用先进、成熟、可靠、稳定、安全的网络和技术，建成一个高带宽、高可靠性、可管理的信息化基础。

采用业界领先的万兆网络交换芯片

具备先进的硬件处理能力和最丰富的业务特性，提供全线速无阻塞交换的能力，满足万兆网络大流量数据无阻塞要求。拥有稳定的交换处理能力，包转发率为96Mpps，背板带宽达128Gbps;真正做到软硬结合，从转发稳定性、数据包处理速度、支持功能业务能力等方面提升产品的品质。 彻底解决高清监控数据传输慢、画面卡顿的现象，极大的满足了用户对高带宽的需求。

快速环网协议，免配置

具有多层交换能力和线速的路由转发能力；保证了这款设备优秀的组网能力，方便连接到骨干网络，扩展了设备的使用范围。稳定可靠的快速环网保护协议(RSTP), 真正实现环路冗余保护。客户在使用交换机时万兆端口直接免配置接入网络，减少网络故障出现的概率。

坚固的网络安全措施

支持IP、MAC、VLAN、端口等用户标识元素的动态或静态绑定，同时实现用户策略(VLAN、QoS、ACL)的动态下发。支持端口隔离，防止同一广播域中2台邻居设备内网之间通讯，减少网络风险；支持风暴控制功能，可对广播、组播、单播风暴进行抑制； 支持特有的ARP入侵检测功能，可有效防止黑客或攻击者通过ARP报文实施日趋盛行的“ARP欺骗攻击”；

灵活多种便捷管理功能

支持命令行配置（CLI）、通过Telnet、Console口进行管理，适合专业的网络管理人员；通过简单的可视化WEB界面（支持http及https协议），可对交换机的各种功能进行简单方便的操作；支持一键恢复出厂设置，使维护更加简单；
