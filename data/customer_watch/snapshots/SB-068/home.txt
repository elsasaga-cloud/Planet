Automation & Programability

We at ICT Integrators have skill set of automating various areas of IT landscape through programming such as:
- Inventory - To be able to understand what is actually there?
- Configuration Drift and Audit - To be able to detecct if there are any changes from the baseline or compliance/security checklist?
- OS Upgrades - Simplified & intelligent management of updates for both network and systems!
- Provisioning & Policy Automation - Creating, Approving and Implementing a policy/configuration change through the IT landscape!
- Workloads - Automating day to day tasks by using pre-build wizards/scripts.
With vast knowledge of multi-vendor API capabilities & functions, we use tested state of the art TOOLKIT such as:
- GiT
- Ansible, Puppet, Jenkins
- Python
- YANG, NETCONF, JSON, REST, XML, YAML, Jinja
- Stackstorm
