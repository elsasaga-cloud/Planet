[ipTIME 공유기] 인터넷 연결 장애 시 해결 방법 Q 사용하던 공유기에서 인터넷이 갑자기 안 돼요. 어떻게 해결하나요? A 모뎀과 공유기를 다시 시작해도 인터넷이 안 되면, 공유기를 초기화한 뒤 MAC 주소 변경으로 외부 IP 주소를 새로 받고 와이파이(Wi-Fi) 이름과 비밀번호를 다시 설정합니다.
인터넷이 갑자기 안 될 때 점검할 사항 (동영상)
※ 동영상이 재생되지 않으면 [동영상 새 창으로 보기] 를 눌러 주세요.
먼저 확인하세요
모뎀과 공유기의 전원을 모두 끕니다. 모뎀 전원을 먼저 켜고, 1분 정도 지난 뒤 공유기 전원을 켭니다.
그래도 인터넷이 안 되면 공유기 WAN 포트에 연결된 랜선을 PC에 직접 연결해 인터넷이 되는지 확인합니다. PC에서도 인터넷이 안 되면 인터넷 회선 문제이므로 통신사에 회선 점검을 요청해 주세요.
※ 아래 STEP은 공유기를 초기화해 모든 설정을 삭제하고 다시 설정하는 방법입니다. 인터넷 연결 방식이 PPPoE나 고정 IP라면 통신사에서 받은 계정이나 IP 주소 정보를 미리 확인해 주세요.
STEP 1 공유기 초기화
공유기 뒷면 또는 앞면의 RST 버튼 을 볼펜처럼 끝이 뾰족한 도구로 CPU LED가 빠르게 깜빡일 때까지(약 10초) 누릅니다. RST 버튼 위치는 모델마다 다릅니다.
※ 초기화하면 모든 설정이 삭제되고 공장 출고 상태로 돌아갑니다.
STEP 2 공유기 관리 화면 접속
공유기에 연결된 PC나 스마트폰의 인터넷 주소 창에 http://192.168.0.1 을 입력하고, 로그인 이름, 암호, 보안문자를 입력해 [로그인] › [관리도구] 를 누릅니다.
※ 로그인 이름에 admin이 입력되어 있다면 암호에도 admin을 입력합니다. 변경한 관리자 암호가 기억나지 않으면 [ipTIME 공유기] 관리자 암호(로그인 암호) 분실 시 해결 방법 을 참고해 주세요.
※ 관리 화면에 접속되지 않으면 [ipTIME 검색기] 를 이용해 접속해 주세요.
STEP 3 MAC 주소 변경 (외부 IP 주소 새로 받기)
인터넷 회선에서 받는 외부 IP 주소는 공유기의 MAC 주소에 따라 정해집니다. MAC 주소를 변경하면 외부 IP 주소를 새로 받아 장애가 해결될 수 있습니다.
네트워크 관리 › 인터넷 설정 정보 를 누릅니다.
[MAC 주소 변경] 을 체크하고 [적용] 을 누릅니다. 이미 체크되어 있다면 해제했다가 다시 체크합니다.
연결 상태에 “인터넷에 정상적으로 연결됨”이 표시되는지 확인합니다.

STEP 1 네트워크 품질
ICC 전체 네트워크 상황을 요약한 통합 대시보드로, 네트워크 히스토리를 바탕으로 주요 품질 지표를 보여 줍니다. 각 지표는 색상으로 등급이 표시되며, 오늘·1주·2주 단위로 비교·분석할 수 있습니다.
스테이션 연결
기간 중 사이트별 최대 스테이션 연결 수를 기준으로 '나쁨/과밀/많음/적정/적음'으로 분류합니다. 과밀·나쁨 사이트를 확인해 단말 과밀로 생길 문제를 미리 막을 수 있습니다.
스테이션 RSSI
스테이션의 최소 RSSI를 기준으로 '나쁨/약함/보통/좋음/우수'로 분류해 신호가 약한 스테이션을 빠르게 찾을 수 있습니다. 등급을 누르면 해당 스테이션 상세 정보를 볼 수 있어 무선 구성을 미리 조정할 수 있습니다.
무선 연결 끊김

[ipTIME 카메라] RTSP로 NVR·PC 프로그램에서 홈캠 보기 Q 밖에 있는 NAS나 VLC에서 집 ipTIME 홈캠 영상을 RTSP로 보려면 어떻게 설정하나요? A ipTIME CCTV 앱에서 RTSP 를 켠 뒤, 공유기에서 TCP 554 포트 를 카메라 IP로 포트포워딩하고, 외부에서 rtsp://admin:비밀번호@공유기외부IP:554/onvif1 로 접속합니다.
ipTIME 홈캠은 RTSP를 지원해 NAS, NVR, VLC 미디어 플레이어 등 RTSP 클라이언트에서 실시간 영상을 볼 수 있습니다. 외부(원격지)의 RTSP 클라이언트에서 접속하려면 카메라가 연결된 공유기에서 RTSP 포트(기본값 TCP 554)를 여는 포트포워딩 설정이 필요합니다.
※ 해당 제품: C300E, C400G, C500G, C400GS, C500GS, C500-Outdoor
※ C300E는 설정 › 설정 더보기 › NVR 연결 에서 RTSP 연결 켜기 를 켜고 패스워드 (RTSP 비밀번호)를 설정합니다.
STEP 1 ipTIME CCTV 앱에서 RTSP 켜기
스마트폰에서 ipTIME CCTV 앱을 실행하고 등록된 카메라에 접속합니다.
오른쪽 위 설정(: :) 아이콘을 누르고 설정 › 하드디스크 녹화기(RTSP) 메뉴로 들어갑니다.
하드디스크 녹화기(RTSP) 를 켜짐(파란색) 으로 변경하고 RTSP 접속용 비밀번호를 만듭니다.
RTSP가 켜지면 admin 계정과 만든 RTSP 비밀번호로 카메라에 접속할 수 있습니다. (계정 이름의 기본값은 admin이며, 하드디스크 녹화기(RTSP) 메뉴의 계정 설정에서 바꿀 수 있습니다. C300E는 NVR 연결의 [계정 변경]에서 바꿉니다. 계정을 바꿨다면 아래 주소와 프로그램에 admin 대신 바꾼 계정을 입력합니다.)
앱의 설정 › 네트워크 정보 에서 카메라의 IP 주소 를 확인합니다.
※ 확인한 카메라 IP 주소는 STEP 2 포트포워딩 설정에 필요하니 기억해 두세요.
STEP 2 공유기 포트포워딩 설정
공유기에 연결된 PC나 스마트폰의 인터넷 주소 창에 http://192.168.0.1 을 입력하고, 로그인 이름, 암호, 보안문자를 입력해 [로그인] › [관리도구] 를 누릅니다.
※ 로그인 이름에 admin이 입력되어 있다면 암호에도 admin을 입력합니다. 변경한 관리자 암호가 기억나지 않으면 [ipTIME 공유기] 관리자 암호(로그인 암호) 분실 시 해결 방법 을 참고해 주세요.
※ 관리 화면에 접속되지 않으면 [ipTIME 검색기] 를 이용해 접속해 주세요.
※ 스마트폰에서는 왼쪽 위 를 누르면 같은 메뉴가 나옵니다. 앱으로 접속하는 방법은 [ipTIME 공유기] 공유기 관리 화면에 접속하는 방법 (PC, 스마트폰, 앱) 을 참고해 주세요.

규칙을 입력하고 [추가] 를 누릅니다.
