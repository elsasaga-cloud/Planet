Flap Barrier and Turnstile Gate for Reading Emirates ID
How Flap Barrier and Turnstile Gate Used for Reading Emirates ID for Access Control Scanning
Overview
Scenario: A Semi Government Office In Dubai, UAE. Required proper security access system using emirates ID as access control credential. They have a large Lobby before the lift lobby where people come in.
Requirement : False proof solution with single access card for all purpose including lift control.
Solution Provided
A set of 4 Flap barrier hidden gate were installed at the access lobby with matrix smart card reader. With the help of newly introduced Matrix Cosec Argo series device, we could use UAE emirates ID for authenticating access entry to the lift lobby. Matrix lift control module enhanced security of the premise further as lift calling and floor allocation is possible only through respective smart card used at the entrance smart gate.
Thanks to full solution from matrix with both hardware and software for various security systems.
