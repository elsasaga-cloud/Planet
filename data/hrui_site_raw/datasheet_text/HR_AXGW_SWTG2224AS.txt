     24-Port 2.5G and 2-Port 10G
    SFP+ Web Managed PoE Switch




  Product Highlights

  n Support 24*2.5Gbps PoE ports+2*10Gbps SFP+ ports

  n Support IEEE802.3, IEEE802.3u, IEEE802.3x, IEEE802.3ab, IEEE802.3z

  n Ethernet Ports support 10M/100M/1G/2.5Gbps self-adaptive

  n Support automatic port flipping (Auto MDI/MDIX)

  n Adopt a storage and forwarding exchange mechanism

  n All ports Support line speed switching

  n The panel indicator LEDs will monitor the working status and assist in fault analysis

  n Support QoS data priority

  n Support Web management

  n Ports 1-4 support BT90W power supply
