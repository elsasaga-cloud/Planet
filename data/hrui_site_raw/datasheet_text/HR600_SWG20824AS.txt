                      14-Port Gigabit Industrial
                          Managed Switch




  Product Highlights

  n Support: IEEE802.3, IEEE802.3u, IEEE802.3x, IEEE802.3z / AB, IEEE802.1Q, IEEE802.1p,
      IEEE802.1d/w
  n Support Spanning Tree STP (802.1D) and RSTP (802.1w), MSTP (802.1s), ERPS
  n Support SNMP v1/v2/v3 Simple Network Management Protocol
  n Support IGMP Snooping, static multicast filtering, and MLD Snooping filtering
  n Support 802.1x port authentication and AAA authentication to enhance network security
  n Support WEB, Telnet, CLI, SSH management
  n IP40 protection level, high-strength aluminum profile shell, DIN35 rail installation
  n Industrial grade 4-level design, operating temperature from -40~75°C
  n Support redundant power supply connection and anti reverse connection
  n Comply with EMC EN55032 standard
