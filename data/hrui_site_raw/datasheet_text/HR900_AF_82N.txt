  8-Port 100Mbps and 2-Port Gigabit
             PoE Switch




  Product Highlights

  n 8* 100Mbps PoE ports and 2* 1G uplink RJ45 port

  n Complies with IEEE 802.3, IEEE 802.3u, and IEEE 802.3x standards

  n RJ45 port supports 10/100Mbps adaptive

  n PoE port automatically activates PoE watchdog mode in VLAN and Extend modes

  n Flow control method: Full duplex uses IEEE 802.3x standard, while half duplex uses Back

    pressure standard

  n Supports automatic port flipping (Auto MDI/MDIX)

  n The panel indicator LED will monitor the working status and assist in fault analysis

  n Supports three modes: VLAN, Default, and Extend
