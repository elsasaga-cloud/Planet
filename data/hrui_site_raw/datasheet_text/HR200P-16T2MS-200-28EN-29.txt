       16-Port Gigabit and 2-Port 2.5G
              SFP PoE Switch




  Product Highlights

  n 16*1Gbps PoE ports+2*2.5Gbps SFP ports

  n Support IEEE802.3, IEEE802.3u, IEEE802.3x, IEEE802.3ab, IEEE802.3z

  n Ethernet Ports support 10/100/1000Mbps self-adaptive

  n Support automatic port flipping (Auto MDI/MDIX)

  n Adopt a storage and forwarding exchange mechanism

  n PoE ports automatically enable PoE watchdog mode in Extend and VLAN modes

  n Support loop protection function

  n The panel indicator LEDs will monitor the working status and assist in fault analysis

  n Ports 1-2 support HiPoE 60W

  n Support PoE priority to be enabled by default, with a priority order of 1-16
