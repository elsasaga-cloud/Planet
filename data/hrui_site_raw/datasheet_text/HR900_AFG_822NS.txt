                 12-Port Gigabit PoE Switch




  Product Highlights

  n 8 *1G PoE ports+2* 1G SFP ports+2* 1G RJ45 ports

  n Complies with IEEE 802.3, IEEE 802.3u, IEEE 802.3ab, and IEEE 802.3x standards

  n RJ45 port supports 10M/100M/1G adaptation

  n PoE port in Extend mode, 7-8 ports force 10Mbps to automatically activate PoE watchdog mode

  n PoE priority is enabled by default, with priority order from 1 to 8 ports

  n Flow control method: Full duplex uses IEEE 802.3x standard, while half duplex uses Back

    pressure standard

  n The panel indicator LED will monitor the working status and assist in fault analysis

  n Support Extend mode
