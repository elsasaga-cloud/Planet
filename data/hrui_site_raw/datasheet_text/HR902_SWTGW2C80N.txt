   8-Port 10G Web Managed Switch




  Product Highlights

  n Supports 8 *10 Gigabit RJ45 ports

  n Supports IEEE802.3, IEEE802.3u, IEEE802.3x, IEEE802.3ab, IEEE802.3z

  n RJ45 port supports 1.25G/2.5G/10G adaptive

  n Supports automatic port flipping (Auto MDI/MDIX)

  n Adopting a storage and forwarding exchange mechanism

  n All ports support line speed switching

  n The panel indicator LEDs will monitor the working status and assist in fault analysis

  n Support QoS data priority

  n Support web management
