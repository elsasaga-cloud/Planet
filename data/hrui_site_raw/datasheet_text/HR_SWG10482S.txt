  Product Highlights

 n 48 *1G RJ45 ports+2* 1G SFP optical ports

 n Complies with IEEE802.3, IEEE802.3u, and IEEE802.3ab standards

 n RJ45 port supports 10M/100M/1G adaptation

 n Supports automatic port flipping (Auto MDI/MDIX)

 n The panel indicator LED will monitor the working status and assist in fault analysis

 n Supports dial switch VLAN mode

 n Flow control method, IEEE802.3x standard for full duplex and Backpressure standard for half

   duplex

 n Support loop alarm
