         24-Port Gigabit Ethernet Switch




  Product Highlights

  n Supports 24 *1G RJ45 ports+2*1G SFP optical ports

  n Supports IEEE802.3, IEEE802.3u, IEEE802.3x, IEEE802.3ab, IEEE802.3z

  n RJ45 port supports 10/100/1G adaptation

  n Supports automatic port flipping (Auto MDI/MDIX)

  n Adopting a storage and forwarding exchange mechanism

  n All ports support line speed switching

  n 1U rack installation

  n The panel indicator LED will monitor the working status and assist in fault analysis

  n Supports 1-8 port QOS priority

  n Supports three modes: VLAN, Default, and Extend
