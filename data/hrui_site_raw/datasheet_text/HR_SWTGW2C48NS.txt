                12-Port 10G Web Managed
                          Switch




  Product Highlights

  n 4* 10G RJ45 ports and 8* 10G SFP+ ports

  n Complies with IEEE 802.3, IEEE 802.3u, IEEE 802.3ab, IEEE 802.3bz, IEEE 802.3ae, and

    IEEE 802.3x standards

  n RJ45 port supports 100M/1G/2.5G/5G/10G adaptive

  n Supports automatic port flipping (Auto MDI/MDIX)

  n The panel indicator LEDs will monitor the working status and assist in fault analysis

  n Flow control method, IEEE802.3x standard for full duplex and Backpressure standard for half

    duplex

  n Support QoS data priority

  n Support Web Management
