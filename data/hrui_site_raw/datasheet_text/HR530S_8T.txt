    8-Port 10G L3 Managed Ethernet
                Switch




  Product Highlights

  n Comply with IEEE 802.1d, IEEE 802.1w, IEEE 802.1s, IEEE 802.1p, IEEE 802.3, IEEE 802.3u,
    IEEE 802.3x, IEEE 802.3z, IEEE 802.3ab, IEEE 802.3ae standards
  n Support L3 management, DHCP Server, QoS, ACL control, SNMP V1/V2/V3, IGMP Snooping
    v1/v2
  n Support Spanning Tree Protocol STP/RSTP/MSTP (ERPS), loop detection and self-healing, and
    remote loopback monitoring and control
  n Support multiple VLAN partitions, including MAC VLAN, protocol VLAN
  n Support IP address+MAC address+VLAN+port binding, DHCP Snooping, IP source and DAI
    protection
  n Support IPV4/IPV6, RIP v1/v2, OSPF v2
