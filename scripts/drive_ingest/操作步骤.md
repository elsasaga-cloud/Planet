> 要在删除前把它们全部留下来，需要让 **GitHub Actions 运行器**把 2,385 个文件（5.7 GB）逐个下载并抽取（Arena 沙箱访问不了 Drive；Drive 连接器抽 Word 会把表格丢掉——规格书的核心全在表格里，所以不能用它）。这一步需要你做 **两件事**（约 5 分钟），之后全自动，预计 1.5–3 小时跑完。

## 一、两件事

### 1. 让运行器能下载：把《SmartByte》文件夹临时设为「知道链接的任何人 · 查看者」
二选一：
- **A（省事）**：在对话里回复一句「**可以共享**」→ 我用 Drive 连接器把文件夹改为「知道链接的任何人 · 查看者」（不可被搜索到），跑完**立刻改回「受限」**。
- **B（自己动手）**：Google Drive → 右键《SmartByte》→ **共享** → 「常规访问权限」从「受限」改成「**知道链接的任何人**」，角色「**查看者**」→ 完成。

> 说明：文件夹里有 SmartByte 给你的成本价、转账汇总等敏感文件。「知道链接的任何人」= 只有拿到链接 / 文件 ID 的人能看，Google 搜索不到；文件 ID 只存在于本私有仓库的索引里。开放窗口只在跑的这几个小时，之后恢复受限。若不接受，请看「四、不想共享怎么办」。

### 2. 保存 workflow 文件（和上次快照 workflow 完全一样的操作）
把本目录的 `drive-smartbyte-ingest.yml` **原样**保存为仓库里的 `.github/workflows/drive-smartbyte-ingest.yml`（分支 `arena/3f35b9b3-planet`）。保存即自动运行。

3. **Add file → Create new file**

5. 把下面「五、文件内容」整段粘贴进编辑框（从 `# T28：` 到最后一行 `git push ...`，不要漏行、不要改空格）
6. **Commit changes…** → 说明填 `T28: 开启 Drive SmartByte 入库 workflow` → **Commit directly to the `arena/3f35b9b3-planet` branch** → **Commit changes**

## 二、运行中会发生什么
- 按 `data/smartbyte_drive_index.json` 里的 2,385 个文件 ID 逐个下载（5.7 GB），顺序：根目录 → 工业管理 → 工业非管理 → 商业管理 → MC → … → 暂时不用的
- 全保真抽取并提交到分支 `data/smartbyte_drive/`：
  - `text/<文件ID>.json`：Word **段落 + 表格（按原顺序）+ 文本框 + 页眉页脚**；Excel 逐表逐行（含隐藏表）；PDF 逐页（无文字层的证书扫描件自动 OCR 中英文）；PPT 逐页（含表格、备注）；XMind 大纲；RAR 里的 MIB 文本；DXF 里的文字；.doc/.pub/.cdr 经 LibreOffice 转换后抽取
  - `thumbs/<文件ID>.jpg`：1,725 张图片 + 9 个视频 + PSD 的缩略图（≤360 px，约 20 KB/张），图片同时做 OCR（有字才存，如管理界面截图）
  - `manifest.json` / `manifest.csv`：每个文件一行：路径、类型、字节、sha256、状态（ok / meta / dup / fail）、抽取方式、字数、重复指向
  - `_coverage.md`：按类型 / 文件夹的覆盖率表 + **失败清单** + 仅元数据清单
- 内容完全相同的文件（912 个重复件）只抽一次，其余写 `same_as` 指向
- **原件备份**：每个顶层文件夹的原始文件打成 ≤1.8 GB 的 zip 分卷，上传到本仓库的 **Release `drive-smartbyte-日期`**（私有仓库，只有协作者能下载；不进 Git 历史，不占仓库体积）。以后要原件就去 Releases 页下载。

## 四、不想共享怎么办（备选）
- 在 Drive 里对《SmartByte》点「**下载**」，Google 会打成几个 ≤2 GB 的 zip 存到你电脑（这本身就是一份本地备份，建议无论如何先做）。
- 然后到仓库 **Releases → Draft a new release**：Tag 填 `drive-smartbyte-manual`，把这些 zip 拖进附件 → **Publish release**。告诉我 tag 名，我改用 Release 里的 zip 作为来源跑同一套抽取，全程不需要共享 Drive。（缺点：要从你这边上传 5.7 GB。）

## 五、文件内容（原样粘贴）
```yaml
# T28：Google Drive《SmartByte》文件夹（5.7 GB / 2,385 文件）删除前的全量入库。
# Arena 沙箱拿不到 Drive 文件字节，Drive 连接器抽文本又会丢 Word 表格，故由 GitHub Actions 运行器
# 按 data/smartbyte_drive_index.json 里的文件 ID 逐个下载（文件夹需临时设为「知道链接的任何人可查看」），
# 全保真抽取正文/表格/逐页/OCR → data/smartbyte_drive/（分批提交回本分支），
# 原件按顶层文件夹打成 ≤1.8 GB 的 zip 分卷上传到本仓库 Release（私有仓库，不进 Git 历史）。
# 注意：代理的 GitHub 连接没有 workflows 权限，无法把本文件推到 .github/workflows/；
# 需要 Simon 在 GitHub 网页上把本文件原样保存为 .github/workflows/drive-smartbyte-ingest.yml
#（分支 arena/3f35b9b3-planet），保存即自动运行（之后代理可通过修改 scripts/drive_ingest/RUN 触发重跑）。
name: Drive SmartByte ingest
on:
  push:
    branches: [arena/3f35b9b3-planet]
    paths:
      - .github/workflows/drive-smartbyte-ingest.yml
      - scripts/drive_ingest/RUN
  workflow_dispatch:
    inputs:
      only_folders:
        description: 只处理这些顶层文件夹（逗号分隔；空=全部）
        default: ""
      only_types:
        description: 只处理这些类型（Word,Excel,PDF,PPT,图片,视频…；空=全部）
        default: ""
      force:
        description: 强制全部重做（1=是）
        default: "0"
      backup:
        description: 原件打包上传 Release（1=是）
        default: "1"
      ocr:
        description: 图片 / 无文字层 PDF 做 OCR（1=是）
        default: "1"
      limit:
        description: 最多文件数（0=不限）
        default: "0"
      source_release:
        description: 备选来源：Release tag（Simon 手工上传的 Drive 打包 zip；空=直接从 Drive 下载）
        default: ""
permissions:
  contents: write
concurrency:
  group: drive-smartbyte-ingest
  cancel-in-progress: false
jobs:
  ingest:
    runs-on: ubuntu-latest
    timeout-minutes: 350
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 1
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - name: Install system tools
        run: |
          sudo apt-get update -qq
          sudo apt-get install -y -qq tesseract-ocr tesseract-ocr-chi-sim tesseract-ocr-chi-tra poppler-utils p7zip-full ffmpeg > /dev/null
          sudo apt-get install -y -qq p7zip-rar > /dev/null || echo "p7zip-rar unavailable"
          sudo apt-get install -y -qq libreoffice-writer libreoffice-draw libreoffice-calc > /dev/null || echo "libreoffice unavailable"
          sudo mkdir -p /mnt/drive_raw /mnt/drive_zip && sudo chown -R "$USER" /mnt/drive_raw /mnt/drive_zip || true
          df -h / /mnt | sed -n 1,4p
      - name: Install python deps
        run: python -m pip install -q -r scripts/drive_ingest/requirements.txt
      - name: Ingest
        env:
          GH_TOKEN: ${{ github.token }}
          GIT_COMMIT: "1"
          GIT_REF: ${{ github.ref_name }}
          RELEASE_TARGET: ${{ github.sha }}
          ONLY_FOLDERS: ${{ github.event.inputs.only_folders || '' }}
          ONLY_TYPES: ${{ github.event.inputs.only_types || '' }}
          FORCE: ${{ github.event.inputs.force || '0' }}
          BACKUP: ${{ github.event.inputs.backup || '1' }}
          OCR: ${{ github.event.inputs.ocr || '1' }}
          LIMIT: ${{ github.event.inputs.limit || '0' }}
          SOURCE_RELEASE: ${{ github.event.inputs.source_release || '' }}
          WORKERS: "6"
          COMMIT_EVERY: "200"
          RAW_DIR: /mnt/drive_raw
          ZIP_DIR: /mnt/drive_zip
        run: |
          git config user.name "drive-ingest[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          [ -w /mnt/drive_raw ] || { export RAW_DIR=/tmp/drive_raw ZIP_DIR=/tmp/drive_zip; }
          python scripts/drive_ingest/ingest.py
      - name: Final commit (safety)
        if: always()
        run: |
          git config user.name "drive-ingest[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git add data/smartbyte_drive || true
          git commit -q -m "T28: Drive《SmartByte》入库（收尾提交 $(date -u +%Y-%m-%dT%H:%MZ)）" || { echo "nothing to commit"; exit 0; }
          git pull -q --rebase -X theirs origin "${{ github.ref_name }}" || true
          git push -q origin "HEAD:${{ github.ref_name }}"
```
