# External Clients 操作步骤（第 1 步导入 / 重渲染）

前提：外部仓库克隆在 `/home/user/.cache/ext/`（沙盒重置后重建）：
```
git clone -q --branch arena/6214ebb8-edgecore --single-branch https://github.com/elsasaga-cloud/Edgecore.git /home/user/.cache/ext/edge
git clone -q --branch arena/01a0c3ef-mikrotik-info --single-branch https://github.com/elsasaga-cloud/mikrotik-info.git /home/user/.cache/ext/mik
git clone -q --branch arena/01a0c908-cctv-poe --single-branch https://github.com/elsasaga-cloud/CCTV-PoE.git /home/user/.cache/ext/cctv
pip install --break-system-packages pyyaml
```

1. `python3 scripts/external_clients/extract_edge.py` → `data/external_clients/edgecore.json`（157）
2. `python3 scripts/external_clients/extract_mik.py` → `data/external_clients/mikrotik.json`（747，仅 A/B）
3. `python3 scripts/external_clients/extract_cctv.py` → `data/external_clients/cctv.json`（03 清单 + profile/ 批次文件 + 单户档案 + smartbyte/ + exhibition/，多处出现按域名/规范名合并；侧表 `cctv_未导入条目.csv` / `cctv_非客户段落.csv` / `cctv_剔除大陆.csv`）
4. `python3 scripts/external_clients/render.py` → `External Clients/<库>/A|B|C/*.md` + `00-索引.md` + `00-总索引.md`（整目录重建，不要手改 MD）

规则：
- 编号 `X<初判等级>-<库字母><序号>` 在抽取时按原编号顺序一次分配；**重跑抽取不会改变既有编号**的前提是来源快照不变——快照换了要先比对 `src_code`，不得重排（第 2 步前把编号固化进 `overrides.json`/独立登记表再换快照）。
- 人工改级：`data/external_clients/overrides.json` `{"XA-M001": {"grade": "B", "reason": "…", "date": "2026-10-28"}}` → 重跑 render.py；档案移到新文件夹，编号不变。
- 初判规则在 `common.py: pregrade()`；国别表 `COUNTRY`；公共邮箱域 `GENERIC`（不参与 Saga 重叠匹配）。
- 大陆公司：抽取时 `grade=DELETE`，不渲染、不编号，只在 JSON 里留痕。
