### C13 · 对位（saga_fit / dayjob_fit）怎么判

- **对位 ✔**：在卖或在用 交换机（商用 / 工业 / PoE / 数据中心）、收发器、PoE 供电设备，与价格主表有同口型；判断材料 = 官网类目 / 商品页 / 品牌列表 / 来信需求 / 快照型号 token。
- **`dayjob_fit`**：视频光端机 / DWDM / 光模块为主 → 不 pass、不算不对位，单列（Simon 本职公司用得上，Q-70）。
- **不对位**：纯 CCTV 摄像头 / 无源配件 / 线缆 / 消费电子 / 与 IT 无关行业。
- **自动对位**：快照 `saga_fit` 默认值只在原值是「默认对位」时替换，原值留 `p1_prev`；P1 型号必须 ∈ 价格主表 `Saga对应型号` ∪ HRUI 型号 ∪ STH 列表。
- **坑**：机检对位标志只看表内字样会漏（LT-R04 212 户）；没有 Saga 型号的需求（bypass / 12+12 / 8 口 2.5G PoE 管理 / 8 GB L3）直说没有，不硬对。
